Environment variables read by the Angular frontend (via injection token ENV):

- NG_APP_API_BASE
- NG_APP_BACKEND_URL
- NG_APP_FRONTEND_URL
- NG_APP_WS_URL
- NG_APP_NODE_ENV
- NG_APP_LOG_LEVEL
- NG_APP_FEATURE_FLAGS
- NG_APP_EXPERIMENTS_ENABLED

If these are not set, sensible defaults are used so the app runs in preview without configuration.
